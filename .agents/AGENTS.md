# Running the Project

When the user asks to "run", "start", or "launch" the site/project, always run all three components:
1. **Website Frontend**: Run `npm run dev` in the project root folder.
2. **Backend Server**: Run `npm run dev` in the `server` folder.
3. **Admin Dashboard**: Direct the user to the admin dashboard path at `http://localhost:5173/#/team-login` with the default details:
   - **Admin Credentials (Online Mode)**:
     - Email: `admin@lokahbuilders.com`
     - Password: `admin123`
   - **Sandbox Passcode (Offline Mode)**: `admin123`

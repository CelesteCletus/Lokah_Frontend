# AUREN ESTATES

A  luxury real estate frontend built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Features

- Cinematic video hero with fallback image
- Premium property listings and filters
- Property details modal with gallery
- AI Property Concierge demo using sample data
- EMI calculator
- Site visit booking form
- Testimonials, contact section, and WhatsApp CTA
- Fully responsive layout

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

This is a frontend demo using placeholder brand data and sample property information. Replace contact details, images, branding, and property data before production handoff.
